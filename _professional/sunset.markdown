Sunset is a project in collaboration with Hôpital Pontchaillou to train nurses in virtual reality before going to the operation room. I participated in making 3 applications:
# Table preparation
The first application is a simulation where an instrumentist nurse gives sterilized tools to the user acting as a scrub nurse, who must place them in specific spots on a table. The player may have to assemble some tools (like a scalpel blade with its handle), or do other actions such as folding a towel or filling a cup.
We developped a number of tools to improve the user experience : hand poses when grabing objects, automatic highlights, autonomous agents.
![screenshot](/img/sunset/montage.jpg)

# Error spotting
In this application, the user plays the role of a nurse just before an operation, and has to make sure that everything is prepared correctly. They must look around the room at every object and person to check expiration dates, holes in packagings, unsafe clothing and more.
The user can teleport around, zoom in on labels to read text, mark objects as incorrect, and interact with a touch screen to access documents.
![screenshot](/img/sunset/ErrorSpottingInteractions.png)

# Tablet application
This final application is meant to be used by many student at once, so it was made to run on tablets that we could give to 20 people in the same room. The user would first visit the operating room freely, then would be presented with a list of situations, and be asked how they would react to those situations.
![screenshot](/img/sunset/Tablette.png)
